# NearFind 시민 안전 데모

🔗 **[라이브 데모 열기](https://hackathon-13-ui6e.vercel.app/)**

- GitHub Pages가 아닌 Vercel 공개 데모입니다.
- 실종 알림, 이동 거리 추적, 리워드, 제보 흐름을 시연할 수 있습니다.

NearFind는 시민이 실종 알림 구역을 안전하게 확인하고, 인상착의 참고 정보와 이동 기록을 바탕으로 필요할 때 제보할 수 있도록 구성한 해커톤용 웹 데모입니다.

## 주요 기능

- **동시 실종 알림 3건**: A/B/C 알림을 지도와 목록에서 함께 확인
- **시간 기반 알림 범위**: 중심부는 진하게, 외곽은 옅게 표시하며 시간 경과 시 범위 갱신
- **사용자 이동 시연**: 사용자 아이콘, 점선·화살표 이동 궤적, 구역 내 이동 거리 표시
- **안심 리워드 시연**: 참고 이미지 확인 보너스와 구역 통과 리워드 제공
- **인상착의 참고 화면**: 실제 얼굴 사진 대신 모자·의류·가방을 표현한 참고 실루엣 사용
- **제보 흐름**: 유형 선택 검증, 데모 위치·메모 입력, 접수 번호와 기관 검토 안내

## 데모 시나리오

1. 홈에서 `실종 알림 A 구역 진입 시연` 선택
2. `인상착의 확인하기` → `계속 이동하기`
3. `12분 경과: 실종 범위 갱신`으로 범위 변화 확인
4. `이동 시연` 버튼으로 `420m → 520m → 650m` 이동 및 리워드 확인
5. `제보하기` → 유형 선택 → 접수 완료

## 구현 방식

- 프레임워크·외부 API·지도 SDK 없이 구현한 단일 정적 웹 앱
- CSS/SVG 지도와 클라이언트 상태로 동작하는 데모
- 실제 GPS, 푸시, 신고 접수, 결제, 실종자 데이터는 사용하지 않음
- Node.js는 로컬 검증과 Vercel 배포 명령에 사용

## 실행 및 배포

```bash
npm run validate
npm run dev
```

Vercel 배포 설정과 상세 절차는 [DEPLOYMENT.md](DEPLOYMENT.md)를 참고하세요.
